# Contribuire a CityMirror / Contributing to CityMirror

Grazie per voler migliorare CityMirror. Manteniamo il progetto leggibile, riproducibile e utile per una discussione urbanistica informata.

Thank you for improving CityMirror. We keep the project readable, reproducible, and useful for informed urban-planning discussion.

## Principi / Principles

- Ogni testo rivolto all'utente e ogni documento deve essere disponibile in italiano e inglese.
- Every user-facing string and document must be available in Italian and English.
- Le formule di stima devono essere spiegabili, testabili e chiaramente presentate come euristiche.
- Estimation formulas must be explainable, testable, and clearly presented as heuristics.
- Non includere chiavi API, dati personali, tiles o contenuti Google Maps nel repository.
- Do not add API keys, personal data, Google Maps tiles, or Google Maps content to the repository.

## Flusso / Workflow

1. Crea un branch descrittivo e mantieni le modifiche circoscritte.
2. Esegui `npm run lint` e `npm run build` prima di aprire una pull request.
3. Spiega impatto, limiti e dati usati; aggiungi screenshot per cambiamenti visivi.

1. Create a descriptive branch and keep changes focused.
2. Run `npm run lint` and `npm run build` before opening a pull request.
3. Explain impact, limitations, and data used; add screenshots for visual changes.
