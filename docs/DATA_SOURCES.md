# Dati e fonti / Data and sources

## Stato MVP / MVP status

Gli indicatori CityMirror sono generati da formule illustrative locali. Non sono dati amministrativi, catastali, di traffico osservato o preventivi di opere. Ogni decisione reale richiede dati autorizzati, controlli normativi e professionisti abilitati.

CityMirror indicators are generated by local illustrative formulas. They are not administrative, cadastral, observed traffic, or construction-budget data. Any real decision requires authorized data, regulatory checks, and qualified professionals.

## Google Maps Platform / Google Maps Platform

Quando configurata, l'integrazione usa Google Maps JavaScript API per la visualizzazione del contesto e Geocoding API per risolvere una ricerca di città. La chiave resta nel browser perché Vite espone le variabili `VITE_*`: deve quindi essere limitata per referrer HTTP e per API nel Google Cloud Console.

When configured, the integration uses Google Maps JavaScript API for contextual display and Geocoding API to resolve a city search. The key resides in the browser because Vite exposes `VITE_*` variables: it must therefore be restricted by HTTP referrer and API in Google Cloud Console.

CityMirror non salva né esporta contenuti o tiles Google. Gli export JSON/GeoJSON contengono soltanto le geometrie schematiche prodotte dal motore CityMirror. Prima di aggiungere altre API, verificare sempre termini, attribuzioni, limiti d'uso e requisiti di caching del fornitore.

CityMirror does not store or export Google content or tiles. JSON/GeoJSON exports only contain schematic geometries created by the CityMirror engine. Before adding other APIs, always verify provider terms, attribution, usage limits, and caching requirements.
